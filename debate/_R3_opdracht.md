Algemene regels:
- Code, data, figuren in experiments/<map>/ (map per agent hieronder). Scripts moeten draaien met `python3 experiments/<map>/<script>.py` vanuit repo-root, deterministisch (seed), en figuren als PNG (matplotlib, Agg) wegschrijven.
- Schrijf per agent experiments/<map>/RESULTATEN.md: per test → vraag, methode, aannames [A], resultaat (laag/basis/hoog), conclusie, en "**alleen met prototype te bevestigen**" + labtestontwerp (opstelling, testobjecten, meetprotocol).
- Elke prestatieclaim koppelen aan berekening/simulatie/bron.
- Max rekentijd per script ~2 min.
